# 微信小程序配置

1. 安装依赖并启动本地 Node.js 服务。
2. 在微信开发者工具中导入根目录，项目指向 `miniprogram/`。
3. 将 `touristappid` 替换为自己的 AppID，或在本地私有项目配置中管理。
   不要把 AppSecret、令牌或签名密钥写入客户端。
4. 修改 `miniprogram/app.js` 中的 `apiUrl` 和 `socketUrl`。工具内调试默认
   为 `http://127.0.0.1:3000` 和 `ws://127.0.0.1:3000`。
5. 真机不能通过手机上的 `127.0.0.1` 访问电脑。为自己的服务配置 HTTPS
   和 WSS，并在平台后台配置 request、socket 合法域名。
6. 示例为工具内调试关闭了域名校验；发布前必须恢复校验，完成自己的
   项目配置、平台审核和所需手续。

网页与小程序使用同一服务端规则。服务端发布不等于小程序发布，协议变更
时需同时更新小程序包。真机音效、震动和切后台重连需单独验收。
